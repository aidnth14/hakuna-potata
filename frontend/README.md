# Hakuna Potata Frontend

This directory contains the production React 19 + TypeScript + Vite frontend application for Hakuna Potata Artisan Bakery.

For complete documentation, design tokens, architecture, and deployment instructions, please refer to:
- [Root README.md](../README.md)
- [Design Specification (DESIGN.md)](../DESIGN.md)
- [LLMs Reference (llms.txt)](../llms.txt)

## Commands

```bash
npm run dev      # Start Vite local development server
npm run build    # Compile TypeScript and build production bundle (strictly <1MB)
npm run preview  # Preview production build locally
```
